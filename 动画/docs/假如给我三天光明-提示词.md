## 0. 参考片拆解：继承什么，改变什么

**继承的语法**
- 近黑底、90% 负空间、单光源（一条缝、一盏灯、一枚太阳）
- 宋体白字 + 衬线斜体英文，字号小、字距大、位置偏下
- 极慢的凝视：单镜 8–16 秒，缓推、缓拉、尘埃漂浮
- 声音极简：低频 drone + 环境声 + 贴耳气声旁白
- 章节之间用 1–2 秒纯黑呼吸

**改变的语法**
- 参考片是「从未见过」的冷寂；本片是「三天之内，逐日变暖」
- 色彩弧线：纯黑 → 琥珀微光 → 灰蓝黎明 →  muted 彩色 → 金色日落 → 黑场余温
- 视觉母题：一束光 → 手掌 → 眼睛 → 水面 → 太阳，反复回到「光落在皮肤上」

## 1. 影片设定

- **一句话**：一个失明的年轻女子，用想象的三天，把「看见」拆成触摸、记忆与告别。
- **结构**：序 24s / 第一天 56s / 第二天 52s / 第三天 48s / 尾声 38s
- **情绪曲线**：黑（0）→ 微光（1）→ 暖（2）→ 亮（3）→ 余温（4）→ 黑（5）
- **旁白**：女声，低声、克制、接近耳语，句与句之间留 0.6–1.2s
- **字幕**：中文思源宋体为主，英文 Cormorant Garamond Italic 为辅；可一键关闭英文
- **叙事**：原创中文旁白，取意于海伦·凯勒散文的公共领域母题，不复用任何现有中译本

## 6. 音乐与音效

## 7. 生成与制作参数

### 7.1 图片生成

- 分辨率：2048×1152（16:9），再放大到 2560×1440
- 采样：Midjourney `--ar 16:9 --style raw --s 150`；即梦/可灵选「电影感 / 写实」
- 种子：固定同一 seed 生成同一场景的变体，保证光影连续
- 每镜出 4 张，选 1 张；优先选「暗部有细节、光有一条边」的
- 统一后期：降饱和 15%、加 35mm 颗粒、轻微 halation、暗角 8%

### 7.2 图生视频（可选）

- 可灵：`camera: slow push in`，`motion strength: 2–3`，禁止大幅运动
- Runway：`slow dolly in, dust motes, subtle light flicker`
- 目标：让静帧「呼吸」，而不是「演起来」

### 7.3 Remotion 实现映射

- 每个镜头 = 1 张静帧 + `<CanvasImage>` + 程序化 Ken Burns（scale 1.0→1.06）
- 叠加层：颗粒噪点、暗角、光晕、极轻的呼吸式亮度起伏
- 字幕：按句切分，逐行淡入；中英双语可开关
- 章节卡：纯黑底 + 宋体标题 + 1.2s 淡入
- 音频：每句旁白单独一条 `<Audio>`，按实测时长排布
- 转场：只用「淡入黑 / 淡出黑」，不用叠化、推拉、故障

## 9. 粒子显影方案（Plan B · 推荐）

> 一句话：全片不出现一张照片。手、脸、婴儿、雕像、街道、太阳，全部由同一种「光尘」粒子聚合成形。

### 9.1 为什么粒子比照片更贴题

- **主题**：一个看不见的人，本来就是在黑暗里用触觉和记忆「拼」出世界。粒子就是她脑中的材料。
- **视觉**：与参考片的黑场、单光源、极简完全同源，甚至更纯粹。
- **一致性**：17 个镜头共用一套粒子语言，不会出现 AI 图风格漂移、换脸、手部崩坏。
- **可复用**：粒子系统写一次，所有镜头复用；改一个参数就能改全片气质。

### 9.2 三种「成形来源」

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| A. 纯 SVG 剪影 | 手画路径 → 在路径内撒点 | 零图片、完全可控 | 解剖结构靠手画，脸和手容易假 |
| **B. 图 → 点云（推荐）** | AI 图按亮度 + 边缘采样成点 | 形状真实，图本身不出镜 | 仍需生成 10 张源图 |
| C. 3D 点云 | GLB 模型顶点 → 粒子 | 可旋转、可换角度 | 需模型资产，成本最高 |

**推荐 B 的原因**：现有 17 条提示词一条都不用改，生成的图只当「点云地图」——按亮度采样、Sobel 边缘加密，转成 1.2–1.8 万个点。**原图永远不会显示**，观众只看到光尘。这样手、脸、婴儿的解剖结构是准的，画面仍然是粒子。

### 9.3 粒子语法（全片统一）

1. **起**：所有粒子从画面中唯一的光点出生（延续「一束光」母题）
2. **聚**：1.5–2.5s 内沿曲线汇入目标点；边缘先到、内部后到
3. **停**：成形后保留 1–2px 微呼吸，5%–8% 的粒子永远不归位（游离尘埃）
4. **散**：向下一个镜头的光点散去，直接成为下一镜的尘埃——**全片不切黑，粒子连续**
5. **景深**：远层小、暗、慢；近层大、亮、快，形成 2.5D 视差

### 9.5 技术实现（Remotion）

```
src/
  particles/
    pointcloud.ts        // 图 → 点云（离线跑，输出 JSON）
    ParticleField.tsx    // Canvas 2D 粒子渲染
    motion.ts            // 聚合 / 停留 / 散开缓动
  data/
    shots.ts             // 17 镜时间轴
public/
  particles/
    s01-hand.json        // {x,y,z,brightness,edge,phase}[]
```

- **渲染**：Canvas 2D + 预渲染 8×8 光点 sprite + `globalCompositeOperation='lighter'`，不用 `shadowBlur`
- **确定性**：`mulberry32(seed)` 固定随机；同一帧永远一样，可重复渲染
- **性能**：1.2–2 万 sprite / 帧，1080p 24fps 可实时预览；卡则降到 1 万并放大 sprite
- **字幕区**：底部 28% 粒子亮度 ×0.45，保证宋体清晰
- **转场**：粒子不淡出，直接飞向下一镜光源，形成「一口气」的连续感
- **章节卡**：粒子暂停，只留 300 颗尘埃在飘

### 9.6 与提示词包的关系

- 第 4 节 17 条 `PROMPT` **全部保留**，用途从「出镜图」改为「点云源图」
- 源图规格可以降：1024×576 足够采样，不需要极致皮肤质感
- 第 7.1 的后期（降饱和、颗粒、halation）不再需要——质感由粒子本身产生
- 新增一条采样规则：**先取亮度，再取边缘**；边缘点权重 ×2，内部点权重 ×0.35

### 9.7 风险与对策

| 风险 | 对策 |
|---|---|
| 粒子脸没有微表情 | 全部用侧脸 / 剪影 / 逆光，避开正脸大特写 |
| 手部结构糊 | 边缘加密 2 倍，指尖、指节单独补点 |
| 粒子太多像星空、失去形体 | 内部密度压到边缘的 35%，并加一层 8% 的暗底 |
| 渲染卡顿 | 预渲染 sprite + 分层降采样；必要时 12k 点 |
| 文字被粒子吃掉 | 字幕区遮罩 + 局部降亮 |

### 9.8 建议的验证顺序

1. **10 秒测试**：S01 手掌聚合 → 停留 → 散开（验证「成形」）
2. **6 秒测试**：S14 日落粒子 + 转场（验证「散开接下一镜」）
3. 确认后批量生成 17 镜点云
4. 接 TTS、字幕、音乐，出全片
