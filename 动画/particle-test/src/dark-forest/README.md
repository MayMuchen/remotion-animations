# 黑暗森林 / THE DARK FOREST

90 秒无旁白科普短片（律动加强版）。1920×1080，30 fps，144 BPM。
独立 Composition：**DarkForest**。原有 **Beyond** 保留。
深邃配乐独立 Composition：**DarkForestDeepSpace**，画面与时间线完全相同，只切换到 `score-abyss.wav`。原版保持使用 `score-groove.wav`。

## 节奏与视觉

延续《越过永夜》的冷蓝与琥珀色、暗场光影、程序化深空和宽银幕构图。
深空恢复版加入三层差速星点、体积星云与尘埃、可自转的行星表面和独立漂移云层；开场主行星与卫星、双文明行星、技术跃迁星球、图解后的近景行星边缘均保留。行星遮挡身后星点，不再让背景穿透球体。镜头使用连续缓推而非每小节跳切，节拍只驱动轻微推近与光效。配乐、90 秒长度、144 BPM 与无旁白设定不变。
学习新参考片 BV1VyWw6sEAg 的「悬念先行 → 数字成为视觉主体 → 示意图逐层展开 → 关键词落点 → 回到最初的问题」结构。
不把参考片中包含人声的低频峰值当成可靠 BPM 估计；本片自行创作 144 BPM 配乐。

- 每拍 12.5 帧，每小节 50 帧；半帧事件显示到最近视频帧。
- 章节均落在完整小节；音乐与图解共用 `rhythm.json`，不是简单倍速。
- 四拍底鼓、反拍军鼓/拍手、切分低音、反拍踩镲与十六分音符细节，配合短促光脉冲、镜头推进和关键词弹入。
- 猜疑链递归事件：28.75 / 30.417 / 32.083 / 33.75 秒。
- 通信出发 / 折返 / 抵达提示：37.5 / 40.833 / 44.167 秒。
- 技术跃迁关键提示：45.417 / 51.25 / 52.5 秒。
- 潜在打击发射 / 命中：57.083 / 58.333 秒；命中前留出半拍静默。
- 广播观察者点亮：61.25 秒起，每半拍一个。
- 沉默章节短暂抽空节奏，为科学边界章节留出呼吸。

没有复制参考片的视频、声音、人物、美术资产或代码到成片。

## 科学边界与来源

1. **概念出处**：刘慈欣《三体Ⅱ：黑暗森林》。两条宇宙社会学公理、猜疑链与技术爆炸是小说中的思想实验。影片明确标注「小说模型前提」「极端假设」「并非已证实的宇宙法则」。
2. **距离演示**：假设静止双方相距 10 光年，信号以光速传播，忽略处理时间，单程 10 年、往返至少 20 年。动画中的时间是压缩示意。
3. **技术图表**：坐标明确标注「示意」，没有使用或暗示真实文明技术数据。
4. **科学背景**：NASA *The Search for Life*，本次访问成功，说明尚无地外生命证据，讨论生命出现频率、可检测技术等未知项：
   https://science.nasa.gov/exoplanets/search-for-life/
5. **参考片研究**：Bilibili《宵禁｜鼓敲满一千下，长安城会发生什么（4K成片）》，BV1VyWw6sEAg。通过公开元数据、关键帧和开场视频样本研究其镜头、数字、关键词与动作节奏。研究记录在 `out/dark-forest/research/`。

「广播暴露坐标」「先清除潜在威胁」均作为这个模型中的可能推演表达，不把它们当成已被实证的星际行为规律。
